# ماژول کراولر جامع تاریخچه گروه تلگرام (Telegram Group Chat Crawler)

این ماژول وظیفه دارد تاریخچه کامل پیام‌ها، متادیتای انواع مدیا (تصویر، ویدئو، ویس، صوت، اسناد و استیکر) و زنجیره ریپلای‌ها را از گروه تلگرامی شما استخراج کرده و در یک دیتابیس با کارایی بالای SQLite (حالت WAL) ذخیره نماید.

---

## ویژگی‌های کلیدی این پیاده‌سازی

1. **بدون دانلود فایل‌های سنگین:** مشخصات کامل رسانه‌ها (`file_id`، ابعاد، فرمت MIME، سایز، مدت زمان ویس/ویدئو، نام فایل) به همراه کپشن ذخیره می‌شود تا حجم دیسک اشغال نشود.
2. **ردیابی ریپلای و سلسله‌مراتب گفتگوها:** فیلدهای `reply_to_msg_id` و `reply_to_top_id` ذخیره می‌شوند تا در مرحله RAG بتوان سوال و جواب‌ها را به هم دوخت.
3. **ذخیره مشخصات فرستنده و ری‌اکشن‌ها:** نام و نام‌خانوادگی، یوزرنیم، نوع فرستنده و ری‌اکشن‌های ثبت‌شده روی پیام.
4. **سیستم Checkpoint و قابلیت Resume:** اگر کراول متوقف شود (یا خطای FloodWait رخ دهد)، در اجرای بعدی دقیقاً از آخرین پیام خوانده‌شده ادامه می‌دهد.
5. **جلوگیری از قفل شدن دیتابیس:** تنظیم SQLite روی حالت `PRAGMA journal_mode=WAL` و `busy_timeout=30000` برای دسترسی همزمان پروسه‌ها.

## ساختار جدول `messages` در دیتابیس

| فیلد | نوع | توضیحات |
| :--- | :--- | :--- |
| `message_id` | INTEGER | شناسه اختصاصی پیام در تلگرام |
| `chat_id` | INTEGER | شناسه گروه |
| `sender_id` / `sender_name` / `sender_username` | TEXT/INT | مشخصات کامل فرستنده |
| `text` / `raw_text` | TEXT | متن پیام یا کپشن مدیا |
| `reply_to_msg_id` | INTEGER | پیامی که این پیام به آن ریپلای زده شده |
| `media_type` | TEXT | نوع مدیا (`photo`, `video`, `voice`, `audio`, `document`, `sticker`, ...) |
| `file_id` / `file_size` / `mime_type` | TEXT/INT | متادیتای اختصاصی فایل رسانه |
| `duration` / `width` / `height` | INT | مشخصات فنی ویس، ویدئو و عکس |
| `grouped_id` | INTEGER | شناسه آلبوم عکس/فایل برای پیام‌های چندتایی |
| `reactions_json` | TEXT | آرایه JSON از اموجی‌ها و تعداد لایک‌ها/ری‌اکشن‌ها |
| `raw_json` | TEXT | ویژگی‌های خام تکمیلی برای انعطاف‌پذیری آینده |

## راهنمای راه‌اندازی و استفاده

### ۱. ساخت فایل متغیرهای محیطی
یک فایل `.env` در کنار `.env.example` بسازید و مقادیر `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` را وارد کنید:
```bash
cp .env.example .env
```

### ۲. ساخت اولیه جداول دیتابیس
```bash
.venv\Scripts\python main.py init
```

### ۳. شروع کراول تاریخچه گروه
```bash
# کراول گروه مشخص شده در .env
.venv\Scripts\python main.py crawl

# یا تعیین دستی گروه و محدودیت تعداد پیام تستی (مثلاً ۱۰۰ پیام اول):
.venv\Scripts\python main.py crawl --target @my_motor_group --limit 100
```

### ۴. مشاهده آمار پیام‌ها و انواع مدیاهای جمع‌آوری شده
```bash
.venv\Scripts\python main.py stats
```

### ۵. مشاهده رکوردهای اخیر ذخیره شده
```bash
.venv\Scripts\python main.py recent -n 20
```
